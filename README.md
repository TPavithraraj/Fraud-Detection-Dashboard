# Financial Fraud Detection Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard developed to analyze financial transaction data and identify fraud patterns. The dashboard provides meaningful insights through visualizations, helping stakeholders monitor fraud trends, high-risk locations, merchant performance, and transaction behavior.

## 🎯 Objectives
- Analyze financial transaction data.
- Identify fraudulent transactions and fraud percentage.
- Monitor fraud trends over time.
- Discover high-risk merchants, states, cities, and transaction categories.
- Support business decisions with interactive visualizations.

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning & Transformation

## 📊 Dashboard Features
- Total Transactions
- Fraud Transactions
- Fraud Percentage
- Total Transaction Amount
- Fraud Amount
- Average Transaction Amount
- Average Fraud Amount
- Top Fraud States
- Top Fraud Cities
- Top Fraud Merchants
- Transaction Category Analysis
- Monthly Fraud Trend Analysis
- Interactive Slicers and Filters
- Drill-through Analysis

## 📈 Business Insights
- Identifies regions with the highest fraud activity.
- Highlights merchants associated with the most fraudulent transactions.
- Tracks fraud trends over time.
- Compares fraud and genuine transactions.
- Supports faster fraud monitoring and decision-making.
